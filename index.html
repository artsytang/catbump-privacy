猫猫大逃亡隐私政策

更新日期：2026年9月3日　 生效日期：2026年9月3日

一、适用范围与运营主体

《猫猫大逃亡》（以下简称“本游戏”）由唐思思开发并运营， 厂商及品牌名称为 Cat Bump。

本政策适用于通过 TapTap 平台运行的《猫猫大逃亡》 TapTap 小游戏版本。

本政策用于说明本游戏处理信息的类型、处理目的、 保存方式，以及用户可以行使的相关权利。

用户可以选择同意或不同意本政策。 不同意不会影响当前版本基础游戏功能的使用， 但需要相关授权的广告、TapSDK 扩展服务或其他第三方功能 将不会初始化或提供。

二、当前版本功能情况

当前版本已接入 TapADN 激励视频广告，用于游戏失败后的可选复活功能。

广告仅在用户同意本隐私政策，并主动点击“看广告继续”按钮后展示。 用户不同意隐私政策或不选择观看广告，仍可使用基础游戏功能并正常进入结算。

当前版本暂未提供或启用以下功能：

  • TapTap 账号登录；
  • 好友关系和聊天；
  • 在线排行榜；
  • 云存档；
  • 应用内购买；
  • 开发者自建账号系统；
  • 开发者自建服务器数据上传。

如果后续版本增加上述功能，我们会在正式启用前， 根据实际处理情况更新本政策。

三、本游戏处理的信息

当用户主动观看激励视频广告时，TapADN SDK 可能根据实际运行环境处理设备基础信息、设备标识符、 网络状态、IP 地址、应用基础信息、广告展示及点击数据、 崩溃与性能数据，用于广告投放、广告监测归因、 广告统计分析及反作弊。

本游戏不会主动申请相机、麦克风、通讯录或精确位置权限。 TapADN SDK 实际处理的信息范围以其官方隐私政策和当前运行环境为准。

  • 游戏设置： 音乐开关、音效开关和震动开关。
  • 游戏记录： 本地最高分等基础游戏数据。
  • 隐私同意状态： 用于判断后续启动时是否再次显示隐私政策提示。

上述数据主要通过 Unity 本地存储机制保存。 当前版本不会由开发者主动将这些数据上传至自建服务器。

当前版本不会由开发者主动要求用户提供以下信息：

  • 姓名、身份证号码和手机号码；
  • 通讯录、短信和通话记录；
  • 精确地理位置；
  • 相机和麦克风内容；
  • 人脸、指纹和声纹等生物识别信息；
  • 银行卡和支付账号等金融信息。

四、信息处理目的

当前版本处理本地数据仅用于以下目的：

  • 保存和恢复音乐、音效和震动设置；
  • 保存和显示本地最高分；
  • 记录用户是否已经同意本隐私政策；
  • 保证游戏界面、音频和基础功能正常运行；
  • 排查游戏运行中的异常问题。

本游戏不会将上述本地数据用于个性化广告、 用户画像、跨应用追踪或与当前游戏功能无关的用途。

五、TapTap 平台及第三方服务

TapADN SDK 激励视频广告服务 上海艾得蒽数字科技有限公司及其关联方 用于激励视频广告投放、广告监测归因、 广告统计分析及广告反作弊 已接入
TapTap 小游戏平台基础服务 易玩（上海）网络科技有限公司 提供小游戏分发、加载、运行环境、 平台兼容和安全保障等基础服务 已使用
TapSDK 登录、数据分析、排行榜、 云存档、好友等扩展服务 易玩（上海）网络科技有限公司 当前版本未使用 未启用
广告服务 暂无 当前版本未接入广告 未启用
其他第三方统计或崩溃分析服务 暂无 当前版本未接入相关服务 未启用

TapTap 平台可能根据其自身服务规则处理平台运行所必需的 设备、应用、网络和运行日志等信息。 该部分信息由 TapTap 平台按照其隐私政策进行处理。

如后续启用 TapSDK 扩展功能，具体信息处理类型和规则 将根据实际启用的服务更新，并参考 TapSDK 隐私政策 。

六、广告服务说明

本游戏接入 TapADN SDK 提供激励视频广告服务。 服务提供方为上海艾得蒽数字科技有限公司及其关联方。

激励视频用于游戏失败后的可选复活。 广告不会自动弹出，只有用户主动点击“看广告继续”后才会尝试展示。

TapADN SDK 可能处理设备基础信息、设备标识符、 网络状态、IP 地址、应用基础信息、广告展示、点击和转化数据、 崩溃数据及性能数据，用于广告投放、监测归因、 统计分析、服务稳定性保障及反作弊。

本游戏仅在本地记录用户是否同意隐私政策。 用户未同意时，不创建或初始化激励视频广告。 用户可以通过清除小游戏本地数据撤回同意； 撤回后，广告功能将不再初始化，但基础游戏功能不受影响。

TapADN SDK 隐私政策： https://ssp.dirichlet.cn/docs/agreement/

七、信息的存储与删除

当前版本的游戏设置、最高分和隐私同意状态主要保存在 当前设备或 TapTap 小游戏本地运行环境中。

当前版本不提供云端同步。 更换设备、清除小游戏数据、清理 TapTap 客户端数据 或平台缓存后，本地记录可能被删除且无法恢复。

用户可以通过 TapTap 客户端提供的数据管理功能， 或通过清除小游戏数据的方式删除相关本地数据。

八、信息共享、转让与公开披露

我们不会出售或出租用户个人信息。

除以下情况外，我们不会主动向其他第三方共享、 转让或公开披露用户个人信息：

  • 已经取得用户明确同意；
  • 为提供用户主动使用的第三方功能所必需；
  • 根据法律法规或有权机关的合法要求；
  • 为保护用户、开发者、平台或其他主体的合法权益所必需。

如果后续因新增功能需要向第三方提供相关信息， 我们会根据实际情况更新本政策并履行必要的告知义务。

九、用户的权利

在法律法规规定的范围内，用户可以行使查询、复制、 更正、删除、撤回同意、限制处理和投诉反馈等权利。

用户撤回同意后，不影响撤回前基于用户同意已经进行的 信息处理活动。

当前版本没有自建账号系统。 本地游戏设置、最高分和隐私同意状态可以通过清除 小游戏本地数据的方式删除。

涉及 TapTap 平台账号或由 TapTap 平台独立处理的信息， 用户可以通过 TapTap 平台提供的功能或联系方式提出请求。

十、未成年人保护

我们重视未成年人的个人信息保护。 未成年人应在父母或其他监护人的同意和指导下使用本游戏。

当前版本不会主动要求未成年人填写姓名、身份证号码、 手机号码、家庭地址等个人敏感信息。

如果 TapTap 平台根据法律法规或平台规则提供实名认证、 未成年人识别或防沉迷服务， 相关信息将由 TapTap 平台或其指定服务提供方 按照其规则进行处理。

监护人如认为未成年人在使用本游戏过程中存在个人信息问题， 可以通过本政策所列联系方式与我们联系。

十一、信息安全

我们会采取与当前游戏规模和信息处理情况相适应的措施， 尽量防止信息受到未经授权的访问、修改、泄露或丢失。

互联网、终端设备和软件运行环境无法保证绝对安全。 用户也应妥善保护自己的设备及 TapTap 平台账号。
